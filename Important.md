## Visual Studio 2022/2026 gibi VSCode üzerinden nasıl cıktı alinir?

Ornekteki gorulen kod/komut terminalde calistirilarak. Windows ortamında olan sistem burada entegre edilebilir.

Örneğin bir sonraki ders için:
dotnet new console -o Hafta2_Degiskenler
cd Hafta2_Degiskenler
dotnet run

Gibi komutlar calistirilabilir.
